## 2025-05-15 - Palette Micro-UX Standards
**Learning:** Connecting labels via 'htmlFor' and 'id' improves accessibility and the clickable area for form elements. Guiding file selection with 'accept' attributes reduces user error. Adding icons (Lucide) provides visual affordance and makes the UI more intuitive. Using animated spinners (Loader2) for async states manages user expectations during long-running tasks.
**Action:** Always ensure labels are properly linked to inputs, add specific 'accept' types for file uploads, and use visual indicators for all async operations.
