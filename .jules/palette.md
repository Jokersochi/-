## 2026-04-15 - Improving File Upload UX and Accessibility
**Learning:** Standard file inputs lack immediate visual feedback, making the upload process feel disconnected. Additionally, without explicit label associations and focus styles, they are inaccessible to keyboard and screen reader users.
**Action:** Always implement a preview for image uploads using object URLs, provide a clear "Remove" action, and ensure form elements are properly labeled with htmlFor/id and have visible focus indicators.
